# Tech news: Northwind Cloud discloses 2025 data breach

> Fictional company and documents, created for the diligence-agents benchmark. Any resemblance to real companies is coincidental.

In June 2025 Northwind Cloud disclosed a data breach in which an attacker used stolen employee credentials to access backup files for 37 customers. In January 2026 a state regulator fined Northwind 2.4 million dollars for delayed breach notification. Northwind said it has since enforced hardware security keys for all staff and hired a new chief information security officer.
